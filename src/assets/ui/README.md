## Style Guide

- ViewBox: 48×48 (module icons), 80×80 (empty states)
- Primary stroke: `#075EC8` (Flynn's blue)
- Accent stroke: `#0B7CFF` (bright blue)
- Fill: `#E6F1FF` (blue soft) on white background
- Stroke width: 2px (main), 1.5px (detail)
- No text inside SVGs
- Scalable — use with any width/height
